🚀 打造專屬 AI 助手 (零基礎上手)

這是一份為初學者量身打造的實戰手冊。我們將使用「Open WebUI 桌面版」，在完全不寫程式碼的情況下，建立你的專屬 AI（例如：UI/UX 顧問）。

📸 [建議配圖：Open WebUI 桌面版乾淨的首頁截圖]

第一階段：下載與安裝

  1. 取得安裝檔：前往官方下載頁面 https://github.com/open-webui/desktop/releases，點擊下載結尾為 .exe 的檔案。
  2. 執行安裝：雙擊下載好的檔案，一路點擊「下一步」直到安裝完成。
  3. 首次啟動：在桌面雙擊圖示開啟，跳出環境設定時保持預設點擊「繼續」。
⚠️ 帳號建立注意：
首次進入系統要求輸入帳號密碼，這僅存放在你這台電腦的本機端，不會連上外網，隨便填寫也能通過。

第二階段：建立與調整模型

  1. 點擊左側選單的 Workspace（工作區），進入 Models（模型） 標籤，點擊 + Create a Model。
  2. Name (名稱)：輸入 UI/UX 設計顧問。
  3. System Prompt (系統提示詞)：貼上角色規則，例如：> 你是一位資深設計師。請針對介面需求提供 UX 與 UI 建議。
  4. 點擊 Save & Create（儲存並建立）。

🧠 破解 LLM 運作迷思 (核心原原理解析)

直接破除觀念誤區，還原 AI 在你電腦中真正的運作架構。

第一章：三大誤解與真相

❌ 誤解：Open WebUI 是幫我處理 API 與轉發資料的核心系統。

✅ 真相：Open WebUI 只是個「展示間（試衣鏡）」。當你要開發自己的網站時，Open WebUI 完全可以關閉，它不參與 API 資料轉發。

❌ 誤解：我的網站 ➔ 呼叫 Ollama ➔ Ollama 去 Open WebUI 找設定 ➔ 回傳。

✅ 真相：你的網站 ➔ 帶著設定直接呼叫 Ollama ➔ Ollama 運算後直接回傳。正式運作時，資料流向是直線的。

第二章：如何呼叫 API？

把你在 Open WebUI 測試好的 System Prompt 直接寫進程式碼發給 Ollama：

fetch('http://localhost:11434/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'llama3', 
    messages: [
      { role: 'system', content: '你是一位資深 UI/UX 設計師...' },
      { role: 'user', content: '評估這個登入畫面？' }
    ]
  })
});

💻 VS Code 開啟你的旅程 (網頁發佈實戰)

寫好漂亮的網頁後，接下來我們要在 VS Code 的終端機 (Terminal) 中使用 Git 指令，將程式碼上傳到雲端，並透過 Vercel 發佈給全世界觀看！

步驟一：Terminal 上載必備指令

在 VS Code 中打開你的終端機，依序輸入以下指令。如果你是第一次使用，必須先設定你的「身份」，否則系統會報錯阻擋你存檔。

💡 破解「Author identity unknown」錯誤：
如果你遇到這個錯誤，代表 Git 不認識你。請先輸入這兩行綁定身份（替換成你的資料）：

git config --global user.email "你的Email"
git config --global user.name "你的暱稱"

完整上傳三步曲：

# 1. 將所有修改過的檔案加入暫存區 (注意 add 後面有空格加句號)
git add .

# 2. 建立存檔點並寫下更新訊息
git commit -m "更新網站內容與聊天室"

# 3. 將程式碼推送到 GitHub 的 main 分支
git push -u origin main

步驟二：GitHub 綁定發佈 App (Vercel)

當程式碼成功推送到 GitHub 後，我們需要讓 Vercel 有權限讀取你的專案，這樣它才能自動幫你架設網站。

🔧 關鍵備註：如何授權增加對應的發佈 App
1. 登入 Vercel 官網 時，務必點擊 「Continue with GitHub」。
2. 此時會跳出 GitHub 的授權畫面 (Authorize application)。
3. 在授權頁面中，你可以選擇 All repositories (允許存取所有專案) 或 Only select repositories (只允許存取特定專案)。
4. 點擊綠色的 Install & Authorize 完成綁定。
5. 綁定完成後，在 Vercel 後台點擊 Import 你的專案，接著點擊黑色的 Deploy，只要 5 秒鐘，你的專案就會生成專屬網址了！
